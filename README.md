# Abhishek Wabale — Futuristic Portfolio

A responsive, dark futuristic developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder and open a terminal inside it.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

To check a production build, run `npm run build`.

## Personalize before publishing

- In `src/App.jsx`, replace `your.email@example.com` with your real email (the `email` constant and the `mailto:` link).
- Replace the generic GitHub and LinkedIn URLs with your profile URLs.
- Add a real resume PDF and wire a download link if you want a resume button.
- Confirm all skill claims and project details are accurate; add repository/demo links and real outcomes where available.
- The Java 21 badge is a visual placeholder; change it to the version you actually use.

## Deploy

You can deploy the built site to Vercel, Netlify, or GitHub Pages. For Vercel/Netlify, import the project repository and use build command `npm run build` with output directory `dist`.
